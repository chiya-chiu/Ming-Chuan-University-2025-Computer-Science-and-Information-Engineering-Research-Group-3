⼤約1944-1945 年，John von Neumann提出，由於程序和數據在邏輯上是同樣，程序也
應該存儲在計算機的內存中。
1.2.1 四個⼦系統
建立在馮諾依曼模型上的計算機將計算機硬件分為四部分⼦系統：存儲器 (memory)、算術
邏輯單元 (arithmetic logic unit)、控制單元 (control unit)和輸入 / 輸出 (input/output)
存儲器 (memory)
內存是存儲區域。這是處理過程中存儲程序和數據的地⽅
運算邏輯單元 (Arithmetic logic unit)
算術邏輯單元  (ALU) 是進⾏計算和邏輯運算的地⽅
控制單元 (Control unit)
控制單元控制存儲器、 ALU 和輸入 / 輸出的操作
輸入 / 輸出 (input/output)
輸入⼦系統接受來⾃計算機外部的輸入數據和程序，⽽輸出⼦系統將處理結果發送給外
界。
1.2.2 The stored program concept( 存儲程序概念 )
馮諾依曼模型指出程序必須存儲在內存中。  這是完全不同於早期計算機的體系結構，其中只
有數據存儲在內存中：他們的任務程序是通過操作⼀組開關或通過改變接線系統。
現代計算機的內存承載著程序及其相應的數據。
這意味著數據和程序都應該具有相同的格式，因為它們存儲在內存中。
1.3 COMPUTER COMPONENTS( 計算機組件 )
計算機由三部分組成：計算機硬件、數據和計算機軟件。
